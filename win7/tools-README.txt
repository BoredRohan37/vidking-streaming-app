Put these files in this folder (next to moviebox-tui.exe\tools):

  mpv.exe        REQUIRED for playback. Use a build of mpv that still runs on
                 Windows 7 (newer official builds may need Windows 10).
                 You may also use a subfolder:  tools\mpv\mpv.exe
  vlc.exe        optional alternative player (tools\vlc\vlc.exe also works)
  yt-dlp.exe     only for downloads of DASH streams
  ffmpeg.exe     only for downloads (merges video and audio)

If a tool refuses to start on your Windows version, try an older release of it.
